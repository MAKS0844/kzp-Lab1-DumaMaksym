# Консольний звіт (Лабораторна №2)

## Призначення
Програма читає записи з `data/input.csv`, перевіряє їх, обчислює показники (за варіантом №8 "Каталог фільмів") та формує звіт у консоль і файл. 
У другій лабораторній роботі було проведено рефакторинг: алгоритм переведено на принципи ООП з використанням інкапсуляції, власних класів-сутностей та `record`.

## Формат входу
Один запис розміщують у рядку, поля розділяють крапкою з комою. Файл кодують у UTF-8. 
Формат для каталогу фільмів: `title:String; director:String; minutes:int; year:int; rating:double`.

## Валідація даних
Правила валідації інкапсульовано в конструкторі класу `Movie` (який викликається через `Movie.Builder`).
Об'єкт відхиляється (викидається `IllegalArgumentException`), якщо:
- Назва або режисер відсутні (null) або є порожніми рядками.
- Тривалість фільму (minutes) або рік випуску (year) є меншими або дорівнюють нулю.
- Рейтинг фільму є від'ємним або не є скінченним числом (NaN/Infinity).
