# Аналізатор фільмів (Lab 1)

Програма на Java для зчитування, парсингу та аналізу даних про фільми з CSV-файлів із записом результатів у текстовий звіт.

## Вимоги
* Java 21
* Maven

## Команди для роботи
* **Збірка проєкту:** `./mvnw clean compile`
* **Запуск програми:** `./mvnw exec:java`
* **Запуск автоматичних тестів:** `./mvnw test`
