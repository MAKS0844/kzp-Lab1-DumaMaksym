# Каталог фільмів (Лабораторна робота №5 - Сховище та CSV-Експорт)

Цей проєкт є виконанням лабораторної роботи №5 з дисципліни «Кросплатформні засоби програмування».
Програма демонструє створення параметризованого сховища, використання рефлексії для універсального експорту даних та парсинг CSV-формату з екрануванням.

## Реалізований функціонал
- Сховище даних: Параметризований клас `Repository<T>` для типобезпечного зберігання та пошуку об'єктів (без використання raw types).
- Модель даних: Плоский запис `MovieRecord` (режисер, тривалість, оцінка, назва, рік) із суворою валідацією та перевизначеними `equals`/`hashCode`.
- Експорт даних: Універсальний рефлексивний `CsvExporter`, який читає метадані з власної анотації `@CsvColumn(RUNTIME, FIELD)`.
- Імпорт даних (Парсер): Власна машина станів `CsvParser` для коректної обробки формату CSV (екранування ком, подвійних лапок та перенесень рядка).
- Обробка помилок: Власний виняток `DataStorageException` із збереженням першопричини помилки (`cause`).
- Тестування: Повне покриття JUnit-тестами, включаючи доказ ідентичності об'єктів після експорту та імпорту (round-trip тест).

## Інфраструктура
Проєкт налаштований за допомогою **Apache Maven** (через Maven Wrapper).
- `.\mvnw.cmd test` — запуск Unit-тестів.
- `.\mvnw.cmd verify` — запуск тестів та статичного аналізатора коду (SpotBugs).
- `.\mvnw.cmd package` — компіляція та створення виконуваного `.jar` файлу (за допомогою `maven-shade-plugin`).

Налаштовано GitHub Actions для автоматичної перевірки (CI) та завантаження створених JAR-артефактів на Windows, macOS та Ubuntu.
