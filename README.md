# Каталог фільмів (Лабораторна робота №4 - Stream API)

Цей проєкт є виконанням лабораторної роботи №4 з дисципліни «Кросплатформні засоби програмування».
Програма демонструє використання Java Stream API для заміни ручних циклів на декларативні конвеєри обробки даних.

## Реалізований функціонал
- Модель даних: Інкапсульовані класи `Movie`, `FeatureFilm`, `Documentary` (з полями режисер, тривалість, оцінка).
- Потокові запити: Відбір (filter), перетворення (map), групування (groupingBy), зведена статистика (summaryStatistics) та складене сортування (Top-N).
- Безпечний пошук: Використання `Optional` для уникнення NullPointerException.
- Тестування: Повне покриття JUnit-тестами крайових випадків (дублікати, межі фільтрів, порожні списки).

## Інфраструктура
Проєкт налаштований за допомогою **Apache Maven** (через Maven Wrapper).
- `.\mvnw.cmd test` — запуск Unit-тестів.
- `.\mvnw.cmd verify` — запуск тестів та статичного аналізатора коду (SpotBugs).
- `.\mvnw.cmd package` — компіляція та створення виконуваного `.jar` файлу.

Налаштовано GitHub Actions для автоматичної перевірки (CI) на Windows, macOS та Ubuntu.
